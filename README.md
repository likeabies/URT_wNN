# Minimal Reproduction: LSTM Unit-Root Classification

This repository implements a **minimal paper-reproduction codebase** for LSTM-based unit-root classification.
It intentionally avoids architecture or training enhancements not specified by the experiment design.

## What is reproduced

- Sequence length: `100`
- Input shape (PyTorch): `(batch, 100, 1)`
- LSTM backbone:
  - input size = 1
  - hidden size = 30
  - 1 layer
  - many-to-one using final hidden state only
- Binary head: `Linear(30, 2)`
- 3-class head: `Linear(30, 3)`
- Unit-root generation by integration of stationary AR(2) base series:
  - `ur1 = cumsum(ur0)`
  - `ur2 = cumsum(cumsum(ur0))`

## Project structure

- `src/data.py`: AR(2) generator, integration, dataset builders, sanity checks
- `src/model.py`: minimal LSTM classifier
- `src/train.py`: Adam + cross-entropy + early stopping
- `src/evaluate.py`: LSTM metrics and ADF comparisons
- `src/adf_utils.py`: ADF wrappers for binary and 3-class baselines
- `src/utils.py`: seed/config/io helpers
- `configs/binary.yaml`: full binary setup + non-theoretical `p` values
- `configs/multiclass.yaml`: full 3-class setup
- `configs/smoke_test.yaml`: tiny, fast verification config
- `scripts/run_binary.py`: binary train/eval
- `scripts/run_non_theoretical.py`: varying-`p` non-theoretical test evaluation
- `scripts/run_multiclass.py`: 3-class train/eval

## Data generation logic

Stationary base process (`ur0`) is sampled as AR(2):

- `phi1, phi2 ~ Uniform(-0.9, 0.9)` until stationarity constraints hold:
  - `-1 < phi2 < 1`
  - `phi1 + phi2 < 1`
  - `phi2 - phi1 < 1`
- `Z_t = phi1*Z_{t-1} + phi2*Z_{t-2} + eps_t`, `eps_t ~ N(0,1)`

Unit-root series are generated by cumulative summation of the stationary base:

- `ur1`: first cumulative sum
- `ur2`: second cumulative sum

## Label mappings (explicit)

- Binary (`H0=unit root`, `H1=stationary`):
  - class index `0` = unit root (one-hot `(1,0)`)
  - class index `1` = stationary (one-hot `(0,1)`)
- 3-class:
  - class index `0` = `ur2` (one-hot `(1,0,0)`)
  - class index `1` = `ur1` (one-hot `(0,1,0)`)
  - class index `2` = `ur0` (one-hot `(0,0,1)`)

## Binary experiment

Implements train/val/test counts from the requested setup and evaluates:

- LSTM: accuracy, empirical size, empirical power
- ADF (no constant/no trend i.e. `regression='n'`) at 1%, 5%, 10%

## Non-theoretical test experiment

Keeps training unchanged and builds unit-root test samples using:

- (13) pure unit root
- (14) stationary -> unit root split at `t=50`
- (15) unit root -> stationary split at `t=50`

For each `p` (unit-root proportion), composition is generated with transparent integer balancing for non-divisible counts.

## 3-class experiment

Uses same LSTM backbone with `Linear(30,3)` head and reports:

- overall accuracy
- class-wise accuracy
- confusion matrix
- ADF class-wise accuracy at 1%, 5%, 10% using iterative differencing rule

## Assumptions where paper is silent

- AR(2) initialization uses zeros at `t<1` and `t<2`.
- ADF lag selection uses `autolag='AIC'`.
- Non-theoretical count splits use balanced integer allocation when exact equal division is impossible.
